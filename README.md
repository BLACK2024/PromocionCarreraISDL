# Sitio web ISDL

Proyecto estático listo para desplegar en Vercel.

- `index.html`: página principal y plan de estudios.
- `styles.css`: estilos y modo oscuro.
- `script.js`: navegación móvil, animaciones y selector de tema.
- `public/logo-isdl.jpeg`: logo institucional.

Para publicar, importar esta carpeta como proyecto en Vercel. El modo elegido se conserva en el navegador mediante localStorage.
